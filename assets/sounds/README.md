# Sounds

Each file is one moment in the game. **To change a sound, replace the file with one of the same name** (MP3, short, with no silence at the start). No code changes are needed; volumes are set in `src/feedback/index.ts`.

| File | When it plays | Source |
| --- | --- | --- |
| `correct.mp3` | A right answer | uisfx "studio" `success` |
| `wrong.mp3` | A wrong answer | uisfx "studio" `error` |
| `tick.mp3` | As the countdown shows 4, 3, 2 and 1 | uisfx "studio" `progress-step` |
| `level-up.mp3` | The level-up screen, as the ring spins | uisfx "studio" `level-up` |
| `high-score.mp3` | A result with a new high score (not perfect) | uisfx "studio" `bonus` |
| `round-perfect.mp3` | Applause: a perfect round, and on the level-up screen | made by `scripts/sounds/make-round-sounds.py` |
| `round-good.mp3` | A round with 4 right | uisfx "studio" `complete` |
| `round-miss.mp3` | A gentle "aww" for a round with 0 or 1 right | made by `scripts/sounds/make-round-sounds.py` |

Only one result sound plays per round: nothing after a level up (its screen already celebrated), applause for 5 right, the high-score sparkle, the good-round chime for 4, the "aww" for 0–1, and **nothing for 2–3**, so an ordinary round never feels like a failure.

The uisfx sounds come from [uisfx](https://github.com/romainsimon/uisfx) 0.4.0 (MIT licence, see `LICENSE-uisfx.txt`). The applause and the "aww" are generated by a script in this repo (a small crowd of clapping noise bursts, and two soft falling notes), since no free applause could be downloaded; a recorded applause from a sound pack would sound more natural. They're a good free starting point; a paid sound pack can replace them file by file.

Tips for replacements: keep answer sounds under about 0.6 s (the quiz moves on quickly), the tick very short and quiet, and the level-up about 0.7–1 s so it lands with the ring's spin.
